# Faith Kola-Olusa (Shinn 信) portfolio

Plain HTML, CSS and JS. No build step.

```
shinn_portfolio/
├── index.html          Home (lock screen, hero, page links)
├── pages/
│   ├── work.html
│   ├── about.html      Community, strengths, why hire me
│   ├── skills.html     Skills and certifications
│   ├── experience.html
│   ├── creative.html
│   └── contact.html
├── css/
│   ├── global.css      Tokens, nav, footer
│   ├── home.css        Home styles
│   └── pages.css       Inner page styles
└── js/
    ├── global.js       Nav state, footer year
    └── home.js         Hero letters, lock screen
```

Change the accent colour with `--lime` and `--deep` at the top of `css/global.css`.
Deploy: push the folder contents to a GitHub repo and enable Pages.
